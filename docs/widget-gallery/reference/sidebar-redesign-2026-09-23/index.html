Widgets: current vs proposed

Visual reference for Linear FDM-996 (slices FDM-997 to FDM-1001). A mockup, not a pixel contract. Colors are the Tokyo Night values sampled from a live screenshot; the QML implementation must use Omarchy tokens. Static renders show each board's default state. The interactive originals (collapse, hover grip, draggable split, tweaks) are the canvas sources in source/.

Color
• Accent is the only default hue
• Status dot + DEMO pill go neutral
• Amber only when it needs attention: drag the Memory tweak past 85%
• Captions use the theme muted gray
• Fade above the pinned shelf hints at more content
Split scroll
• Monitors/windows keep their natural height up to a cap, then scroll on their own
• Widgets fill the rest and scroll on their own; the WIDGETS header never leaves
• Drag the bar above WIDGETS to move the split (Play mode)
• Tweak ‘Many windows’ off to see widgets take the freed space
• Both regions keep a minimum height
Surfaces
• Cards use the monitor fill (#1f202c), not a darker well
• Header + body share one surface; the divider alone splits them
• Hover highlights the header only
• One 3px radius everywhere; tiles/inputs never rounder than the card
Type & chrome
• WIDGETS label matches PINNED (caption, muted, caps)
• Add/Manage → quiet + icon button
• Titles DemiBold like monitor names; muted when collapsed
• Grip (⋮⋮) shows only on hover/focus
• Collapse uses ▾/▴, so › keeps meaning ‘open’
• Shared 9px text inset for labels and content
